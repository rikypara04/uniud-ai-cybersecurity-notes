Kolmogorov Complexity and Its Relation to Entropy

Lecture 8 - 27 October 2026

1 Encoding Turing machines

Kolmogorov complexity measures the descriptive complexity of an individual string. To define it, a program must itself be represented as a finite string that can be supplied to a universal Turing machine.

Let a Turing machine be described schematically by

\[ m=(K,\Sigma,\delta,s), \]

where:

Component Meaning Role in the finite description
\(K\) finite set of states determines the control states that must be encoded
\(\Sigma\) finite tape alphabet determines the symbols that may be read and written
\(\delta\) transition function returns a next state or special outcome, a symbol to write, and a head movement
\(s\in K\) initial state identifies where execution begins

The tape is unbounded, but the machine description is finite. A configuration consists of the current state, the finite non-blank portion of the tape, and the head position.

A universal Turing machine \(U\) receives an encoding of another machine \(m\) and simulates it. When the simulated machine halts with a string \(x\) on its output tape, write

\[ U(m)=x. \]

The notation \(m(x)\) can likewise be read as the result produced by machine \(m\) on the relevant input.

1.1 A binary representation of a machine

The universal Turing machine is written as

\[ U=(\mathbb Z_U,\Sigma_U,\delta_U,s_U), \]

and its tape alphabet must contain at least the symbols needed to write binary descriptions and control the tape representation. In the notation used in the lecture,

\[ \Sigma_U \supseteq \{0,1,\sqcup,\triangleright\}. \]

where \(\sqcup\) is the blank symbol and \(\triangleright\) is the left-end or start marker. The first two symbols, \(0\) and \(1\), are the symbols from which the binary encoding is constructed.

NoteStatus of the separator symbol

The notes explicitly write \(\Sigma_U\supseteq\{0,1,\sqcup,\triangleright\}\), without including a semicolon. The tape drawing nevertheless uses ; between variable-length fields. The chapter preserves both facts without silently modifying the stated alphabet: ; is treated as a separator in the schematic representation. For ; to be an actual symbol written on the tape, it would also have to belong to \(\Sigma_U\); alternatively, the separator must be implemented through a binary self-delimiting encoding. The lecture notes do not resolve which interpretation is intended at this point.

The machine to be encoded is

\[ m=(K,\Sigma,\delta,s), \]

with transition function

\[ \delta: K\times\Sigma \longrightarrow \bigl(K\cup\{\mathrm{yes},\mathrm{no},\mathrm{halt}\}\bigr) \times\Sigma\times\{\rightarrow,\leftarrow,-\}. \]

The movement component uses \(\rightarrow\) to move one tape cell to the right, \(\leftarrow\) to move one tape cell to the left, and \(-\) to leave the head on the current cell. The three special outcomes in the codomain are not members of \(K\). Consequently, the encoding must assign numbers not only to the states in \(K\) and the symbols in \(\Sigma\), but also to \(\mathrm{yes}\), \(\mathrm{no}\), and \(\mathrm{halt}\).

1.1.1 Numbering the states and halting outcomes

Let

\[ K=\{s,q_0,\ldots,q_{|K|-2}\}. \]

There are \(|K|\) states in total: the initial state \(s\) plus the remaining \(|K|-1\) states. The lecture assigns consecutive integers as follows:

\[ \nu(s)=0, \]

\[ \nu(q_i)=i+1 \qquad \text{for }i=0,\ldots,|K|-2. \]

Thus the ordinary states use exactly the integers

\[ 0,1,\ldots,|K|-1. \]

The three special results appearing in the codomain of \(\delta\) are placed immediately after the ordinary states:

\[ \nu(\mathrm{yes})=|K|, \qquad \nu(\mathrm{no})=|K|+1, \qquad \nu(\mathrm{halt})=|K|+2. \]

Object Assigned integer or range
initial state \(s\) \(0\)
remaining states \(q_0,\ldots,q_{|K|-2}\) \(1,\ldots,|K|-1\)
\(\mathrm{yes}\) \(|K|\)
\(\mathrm{no}\) \(|K|+1\)
\(\mathrm{halt}\) \(|K|+2\)

This numbering explains the labels \(|K|\), \(|K|+1\), and \(|K|+2\) written above \(\mathrm{yes}\), \(\mathrm{no}\), and \(\mathrm{halt}\) in the notes.

1.1.2 Numbering the tape alphabet

The symbols of \(\Sigma\) are numbered after all the state and outcome codes. If

\[ \Sigma=\{a_0,a_1,\ldots,a_{|\Sigma|-1}\}, \]

then

\[ \nu(a_j)=|K|+3+j \qquad \text{for }j=0,\ldots,|\Sigma|-1. \]

Therefore, the alphabet symbols occupy the consecutive range

\[ |K|+3,\ |K|+4,\ \ldots,\ |K|+|\Sigma|+2. \]

Equivalently, using a half-open interval, their codes lie in

\[ [\,|K|+3,\ |K|+|\Sigma|+3\,). \]

The upper endpoint is excluded. This is why the first alphabet code is \(|K|+3\), while exactly \(|\Sigma|\) integers are reserved for alphabet symbols.

Category Number of objects Codes used
states in \(K\) \(|K|\) \(0,\ldots,|K|-1\)
special outcomes \(3\) \(|K|,|K|+1,|K|+2\)
symbols in \(\Sigma\) \(|\Sigma|\) \(|K|+3,\ldots,|K|+|\Sigma|+2\)

The three ranges are disjoint. Hence, after decoding an integer, \(U\) can determine whether that integer denotes an ordinary state, a special outcome, or a tape symbol.

1.1.3 Encoding the sizes and the transition table

To reconstruct \(m\), the universal machine first needs the two sizes

\[ \operatorname{bin}(|K|) \qquad\text{and}\qquad \operatorname{bin}(|\Sigma|). \]

Once these values are known, the numerical ranges above are determined. The remaining part of the description contains the finitely many entries of \(\delta\).

For example, the transition appearing in the notes is

\[ \delta(q_0,a)=(q_1,b,\rightarrow). \]

This means that, when the machine is in state \(q_0\) and reads \(a\), the machine enters state \(q_1\), writes \(b\), and moves one cell to the right. The transition is encoded field by field as

\[ \operatorname{bin}(\nu(q_0))\ ;\ \operatorname{bin}(\nu(a))\ ;\ \operatorname{bin}(\nu(q_1))\ ;\ \operatorname{bin}(\nu(b))\ ;\ \operatorname{bin}(\rightarrow). \]

A transition ending in \(\mathrm{yes}\), \(\mathrm{no}\), or \(\mathrm{halt}\) is encoded in exactly the same way, using the respective codes \(|K|\), \(|K|+1\), or \(|K|+2\) in the next-state field.

The complete description therefore has the conceptual form

\[ \triangleright\ \operatorname{bin}(|K|)\ ;\ \operatorname{bin}(|\Sigma|)\ ;\ \operatorname{bin}(\nu(q_0))\ ;\ \operatorname{bin}(\nu(a))\ ;\ \operatorname{bin}(\nu(q_1))\ ;\ \operatorname{bin}(\nu(b))\ ;\ \operatorname{bin}(\rightarrow)\ ;\ \cdots. \]

Every rectangle below is one cell of the input tape of \(U\). The concrete first fields reproduce the values written in the notes: 10100 for \(\operatorname{bin}(|K|)\) and 1111 for \(\operatorname{bin}(|\Sigma|)\).

▷ 10100 ; 1111 ; ...... ; ...... ; ...... ; ...... ; ......

Figure: the first two groups are \(\operatorname{bin}(|K|)=10100\) and \(\operatorname{bin}(|\Sigma|)=1111\). The following groups encode, in order, \(q_0\), \(a\), \(q_1\), \(b\), and the movement \(\rightarrow\).

1.2 Why a separator matters

If \(\Sigma_U\) contained only \(0\) and \(1\), concatenated binary integers would not reveal their own boundaries. A fixed field width cannot solve the problem for every Turing machine because there is no fixed upper bound on the number of states or symbols.

The lecture described a binary-only workaround:

  • encode each data bit twice, so \(0\) becomes \(00\) and \(1\) becomes \(11\);
  • reserve a mixed pair, such as \(01\), as a separator or stop sequence.

The reserved pair can never occur inside a doubled data word. This makes the representation unambiguous, but doubles the part of the description written with the repetition code. If a separator symbol is made available directly to \(U\), the encoding obtains sharper additive bounds later. In the written definition above, however, the separator is not explicitly listed as a member of \(\Sigma_U\).

Original item Binary-only representation Purpose
data bit \(0\) 00 doubled data symbol
data bit \(1\) 11 doubled data symbol
field boundary 01 reserved separator, impossible inside doubled data

For instance, the data word 100011 becomes 110000001111. The pair 01 can then be inserted as a stop sequence without being confused with encoded data.

2 Kolmogorov complexity

Fix a universal Turing machine \(U\). The Kolmogorov complexity of a string \(x\) relative to \(U\) is the length of the shortest binary description of a machine that makes \(U\) output \(x\):

\[ K_U(x)=\min_{m:U(m)=x}|m|. \]

Here \(|m|\) is the length of the binary encoding of \(m\). Kolmogorov complexity therefore asks for the shortest effective description of one specific string, rather than the average description length of a random source.

2.1 Conditional Kolmogorov complexity

For strings \(x\) and \(y\), the conditional Kolmogorov complexity of \(x\) given \(y\) is

\[ K_U(x\mid y)=\min_{m:U(m,y)=x}|m|. \]

The auxiliary string \(y\) is supplied to the universal machine and is not counted as part of the program length. The quantity measures the additional description needed to produce \(x\) once \(y\) is already known.

2.1.1 Example: a long string of zeros

Let

\[ x=0^n=\underbrace{00\cdots0}_{n\text{ zeros}}. \]

If the value of \(n\) must be included in the program, the program needs both:

  • instructions that print a zero repeatedly;
  • a representation of the number \(n\).

The two situations in the notes are visually different:

If \(n=|x|\) is instead supplied as conditional information, a fixed loop suffices:

for i = 1 to |x|:
    print(0)

The corresponding tape picture has a fixed program followed by the auxiliary input \(n\):

▷ Print(0) ; bin(n) □□

Figure: the program is fixed; only the auxiliary input \(n=|x|\) varies. The output is \(0^n\).

The loop has constant size, independently of \(n\). Consequently,

\[ K_U(0^n\mid n)=O(1). \]

The important distinction is between receiving \(n\) as an external input and hard-coding \(n\) inside the program. In the latter case, the bits used to represent \(n\) contribute to the program length.

3 Dependence on the universal machine

At first sight, \(K_U(x)\) depends on the chosen universal machine. Suppose that \(U\) and \(A\) are two universal Turing machines, and let \(m_A\) be a shortest program for \(x\) on \(A\). Thus

\[ A(m_A)=x \qquad\text{and}\qquad |m_A|=K_A(x). \]

Machine \(U\) can simulate \(A\) when it receives a fixed description of \(A\), a separator, and \(m_A\).

On the input tape of \(U\), this is the block structure drawn in the notes:

▷ ......... ; ............

Figure: the left block is \(\operatorname{bin}(A)\), a fixed interpreter description. The right block is \(\operatorname{bin}(m_A)\), the shortest \(A\)-program that produces \(x\).

Hence

\[ K_U(x)\le |\langle A\rangle|+1+|m_A|, \]

so

\[ K_U(x)\le K_A(x)+c_A, \]

where \(c_A=|\langle A\rangle|+1\) is independent of \(x\). Exchanging the roles of \(U\) and \(A\) gives the reverse inequality up to another constant. Therefore, for some constant \(c_{U,A}\),

\[ |K_U(x)-K_A(x)|\le c_{U,A}. \]

This is the invariance property: changing the universal description language changes Kolmogorov complexity by at most an additive constant. A compiler or interpreter gives the same intuition. A program written in one Turing-complete language can be executed in another by adding a fixed translator whose length does not grow with the output string.

Once a reference universal machine has been fixed, the subscript is usually omitted and the complexity is written simply as \(K(x)\).

4 Basic properties

4.1 A direct upper bound

Consider a universal machine with two behaviours selected by its first bit:

  • if the first bit is \(0\), it interprets the rest of the input as a machine description and performs universal simulation;
  • if the first bit is \(1\), it prints the remaining input verbatim.

Then \(1x\) is a program that outputs \(x\). For this particular machine,

\[ K_U(x)\le |x|+1. \]

By the invariance property, for any fixed reference universal machine,

\[ K(x)\le |x|+c. \]

The book’s binary-only model has no separate delimiter. Repeating the bits so that a reserved binary stop sequence remains available gives the weaker direct estimate

\[ K(x)\le 2|x|+c. \]

The factor \(2\) is an encoding overhead, not an intrinsic property of the string. The lecture’s machine model with a separator avoids it.

A binary-only description can also reduce the overhead by first encoding \(|x|\) in a self-delimiting way and then writing \(x\) without repetition. This changes the dominant term from approximately \(2|x|\) to \(|x|\) plus a logarithmic description of the length. Iterating the same idea pushes the remaining overhead into progressively smaller iterated logarithmic terms. The lecture used this observation only to explain the role of separators and did not develop a new complexity notion from it.

4.2 Existence of incompressible strings

For every integer \(k\), fewer than \(2^k\) binary programs have length strictly less than \(k\):

\[ \sum_{i=0}^{k-1}2^i=2^k-1. \]

Each terminating program produces at most one output string. Therefore, fewer than \(2^k\) strings can have Kolmogorov complexity less than \(k\).

There are exactly \(2^k\) binary strings of length \(k\). By the pigeonhole principle, at least one length-\(k\) string is not produced by any program shorter than \(k\). Hence, for every \(k\), there exists a string \(x\in\{0,1\}^k\) such that

\[ K(x)\ge k=|x|. \]

This is an existence statement. It does not provide an algorithm for identifying a particular incompressible string.

Objects counted Number
binary programs of length \(i\) \(2^i\)
binary programs of length less than \(k\) \(\sum_{i=0}^{k-1}2^i=2^k-1\)
binary strings of length exactly \(k\) \(2^k\)

Since there are more length-\(k\) strings than shorter programs, at least one length-\(k\) string cannot be named by a program of length below \(k\).

4.3 Non-computability

Kolmogorov complexity is mathematically well defined but not computable. To determine \(K(x)\) exactly, an algorithm would need to decide whether each shorter candidate program eventually outputs \(x\) or runs forever. Non-termination prevents such a general decision procedure.

The difficulty is stronger than merely not knowing a shortest program: in general, even the length of that shortest program cannot be computed algorithmically. This is why useful results about Kolmogorov complexity are commonly expressed as upper and lower bounds.

5 The Kolmogorov code

Fix the universal machine \(U\). For each string \(x\), choose a shortest machine description \(m_x\) that outputs \(x\), and define

\[ \varphi_K(x)=m_x. \]

Then, by definition,

\[ |\varphi_K(x)|=K(x). \]

The map \(\varphi_K\) is the Kolmogorov code. Its encoder is not computable, because selecting \(m_x\) would compute \(K(x)\). Its decoding operation is conceptually clear: simulate the encoded machine on \(U\) and read its output. Under the self-delimiting machine representation used in the lecture, the descriptions form a uniquely decodable code.

Unlike the symbol-by-symbol codes studied earlier, this code is defined directly on complete strings. A codeword is itself a machine description capable of generating its decoded string.

6 From Kolmogorov complexity to Shannon entropy

Let \(A\) be a finite source alphabet and let \(P\) be a probability distribution on \(A\). Consider strings

\[ X^m=(X_1,\ldots,X_m)\in A^m \]

produced by a stationary memoryless source, so the symbols are independent and identically distributed according to \(P\). The induced distribution on \(A^m\) is denoted by \(P^m\).

The expected length of the Kolmogorov code over length-\(m\) strings is

\[ \mathbb E_{P^m}[|\varphi_K(X^m)|] = \sum_{x\in A^m}P^m(x)|\varphi_K(x)| = \sum_{x\in A^m}P^m(x)K(x) = \mathbb E_{P^m}[K(X^m)]. \]

Because the Kolmogorov descriptions are treated as a uniquely decodable code, Shannon’s lower bound on expected codeword length gives

\[ \mathbb E_{P^m}[K(X^m)]\ge H(P^m). \]

For a memoryless source,

\[ H(P^m)=mH(P), \]

and therefore

\[ \frac{1}{m}\mathbb E_{P^m}[K(X^m)]\ge H(P). \]

The left-hand side is the expected intrinsic algorithmic complexity per source symbol. Entropy is thus a lower bound for its expected value.

7 From source codes to programs

The converse comparison starts from the observation that every effective uniquely decodable source code can be interpreted as a program-producing mechanism.

Let \(\varphi\) be such a code and let \(D_\varphi\) be a fixed decoder. Given the concatenation of

  1. a description of \(D_\varphi\);
  2. a separator;
  3. the codeword \(\varphi(x)\),

universal machine \(U\) can reconstruct \(x\). This gives a particular program for \(x\), so minimality of Kolmogorov complexity implies

▷ Decoder ; φ(x)... □□

Figure: a fixed decoder description followed by the codeword \(\varphi(x)\) forms a program that produces \(x\).

\[ K(x)\le |D_\varphi|+1+|\varphi(x)|. \]

Taking expectations over \(A^m\) yields

\[ \mathbb E_{P^m}[K(X^m)] \le |D_\varphi|+1+\mathbb E_{P^m}[|\varphi(X^m)|]. \]

7.1 Choosing the Shannon code

Let \(\varphi_S\) be the Shannon code for the distribution \(P^m\). Its expected length satisfies

\[ \mathbb E_{P^m}[|\varphi_S(X^m)|] < H(P^m)+1 = mH(P)+1. \]

The Shannon decoder is determined by the distribution \(P\). A shortest effective description of \(P\) can therefore be used as part of a program implementing that decoder. Absorbing fixed implementation details into the machine-dependent constant, the lecture writes this decoder cost as \(K(P)\). Hence

\[ \mathbb E_{P^m}[K(X^m)] \le K(P)+mH(P)+1. \]

After division by \(m\),

\[ \frac{1}{m}\mathbb E_{P^m}[K(X^m)] \le H(P)+\frac{K(P)+1}{m}. \]

The two directions can be compared directly:

Direction Construction used Result
entropy lower-bounds expected algorithmic description length treat shortest machine descriptions as a uniquely decodable code \(H(P^m)\le \mathbb E[K(X^m)]\)
entropy upper-bounds the normalized expectation asymptotically turn a Shannon codeword and its decoder into a program \(\mathbb E[K(X^m)]\le K(P)+mH(P)+1\)

Combining the lower and upper bounds gives

\[ H(P) \le \frac{1}{m}\mathbb E_{P^m}[K(X^m)] \le H(P)+\frac{K(P)+1}{m}. \]

The term \(K(P)+1\) does not depend on the block length \(m\). Therefore,

\[ \lim_{m\to\infty} \frac{1}{m}\mathbb E_{P^m}[K(X^m)] =H(P). \]

The conclusion concerns the expected Kolmogorov complexity of strings generated by the source, normalized per symbol. It does not claim that every individual length-\(m\) string has complexity exactly \(mH(P)\).
